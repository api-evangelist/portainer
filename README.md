Portainer provides a centralized multi‑cluster management platform for Kubernetes, Docker, Swarm and Podman workloads. It offers enterprise identity and access features such as SSO, LDAP and OIDC, as well as GitOps deployment workflows and self‑service guardrails. The product is aimed at engineering teams and enterprises that need to govern containerized applications across on‑premises, cloud and edge environments from a single console.

**Areas:** Container Management · Containers · Docker · Kubernetes · Kubernetes Management · Enterprise Identity · GitOps

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Portainer: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
